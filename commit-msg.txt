feat: feedback visuel + logs pour le refresh 60s

Le user a signale que le refresh ne se fait pas toutes
les minutes et que ca n'a jamais marche.

Cause probable : le refresh se fait bien en arriere-plan
(meme deux fois par minute via tickLive + refreshForecastIfNeeded)
mais c'est INVISIBLE si les donnees sont identiques entre
2 fetches (meteo stable). Le user croit donc que rien ne
se passe.

Fix : ajouter un feedback visuel explicite pour que le
user PUISSE VOIR le refresh se produire :

1. CONSOLE LOGS
   A chaque tickLive : "[Refresh] tickLive fetch OK en Xms"
   A chaque refreshForecastIfNeeded : "[Refresh] Forecast
   complet OK en Xms (next dans 60s)"
   Ouvre la console (F12) pour verifier le rythme.

2. FLASH VISUEL SUR LE HOURLY
   Ajout d'une animation box-shadow verte breve (0.6s)
   sur le conteneur #hourly chaque fois que les donnees
   sont mises a jour. Permet de voir a l'oeil nu quand
   le refresh se produit.

3. SYNCHRONISATION state.lastRefreshMs
   refreshForecastIfNeeded met aussi a jour
   state.lastRefreshMs et appelle updateUpdatedAt()
   pour que le "Mis a jour il y a X" se rafraichisse
   visiblement.

4. CSS ANIMATION
   Ajout de .hourly.refresh-flash avec @keyframes
   hourly-refresh-flash (box-shadow 0 -> 4px -> 0)

Pour verifier sur le live (https://tomtechclair.github.io/M-t-o/) :
- Recharger (Ctrl+F5)
- Attendre 60s
- Le bandeau horaire doit flasher en vert
- La console (F12) doit montrer les logs toutes les 60s
- Le "Mis a jour il y a X" doit changer toutes les 60s
