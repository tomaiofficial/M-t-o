feat: thunderstorm hyper-reliable cross-validation (Open-Meteo + Met.no)

Le user veut que la meteo soit hyper-fiable pour les orages
en particulier. Implementation :

1. Detection croisee intelligente (anti faux positifs) :
   - Open-Meteo et Met.no utilisent des modeles numeriques
     differents (Arome-MetCoCo / ECMWF pour Met.no,
     combinaison GFS + ECMWF + ICON pour Open-Meteo).
   - Quand les deux detectent un orage au meme endroit/moment,
     c'est quasiment toujours confirme (fiabilite haute).
   - Implementation : fetchWeatherReliable appelle Open-Meteo
     d'abord. Si Open-Meteo detecte un orage (codes WMO 95/96/99
     dans les prochaines 24h), on appelle Met.no en cross-check.
     - Si Met.no confirme -> _thunderReliability.confidence = 'high'
     - Si Met.no ne detecte pas -> 'medium' (1 seule source)
     - Si Met.no echoue (rate-limit, reseau) -> 'medium' quand meme
   - Si Open-Meteo ne predit PAS d'orage, on economise un appel
     a Met.no et on garde une confiance 'none'.
   - Si Open-Meteo a totalement echoue, Met.no prend le relais
     en fallback avec confiance 'medium'.

2. Helpers de detection :
   - THUNDER_WMO_CODES = Set([95, 96, 99]) codes WMO orage
   - analyzeThunder() extrait thunderHours[] + maxIntensity
     (0=orage simple, 1=avec grele legere, 2=avec grele forte)
   - attachThunderReliability() applique l'analyse a une source
   - mergeThunderReliability() fusionne Open-Meteo + Met.no

3. Description enrichie :
   - Si confidence 'high' : "Orages confirmes par double
     validation meteorologique, [avec grele]. Restez a l'abri."
   - Si confidence 'medium' + code actuel orage : "Orages en
     cours, restez a l'abri (verification en cours)."

4. Bandeau visuel d'alerte orage (#thunderBanner) :
   - Affiche : icone eclair + timing ("imminent"/"dans X min")
     + label intensite (grele possible/forte)
     + badge "CONFIRME 2 sources"
   - Couleurs : orange-rouge avec box-shadow pulse
   - Animation keyframes thunder-banner-pulse 2.4s infinie
   - Visible UNIQUEMENT si confidence 'high'
   - Css : .thunder-banner avec gradient orange,
     box-shadow pulsante, badge arrondi pour la confiance
