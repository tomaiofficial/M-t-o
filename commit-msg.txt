feat: switch back to Open-Meteo + precise temperatures + 10 days

Remplacement de Pirate Weather par Open-Meteo :
- Plus simple : pas de cle API, pas de quota
- 10 jours de forecast au lieu de 7-8 (Open-Meteo va jusqu'a 16)
- Endpoint unique : current + hourly 24h + daily 10j

Implementation :
- callOpenMeteo(lat, lon, signal) : un seul appel API avec tous
  les datasets (current, hourly, daily forecast_days=10)
- openMeteoToInternal(json) : conversion directe vers le format
  interne deja utilise par l'app (memes champs que la version
  precedente quand Open-Meteo etait utilise)
- Tronconne hourly pour ne garder que les 24 prochaines heures
  a partir de maintenant
- Le fallback procedural est conserve si Open-Meteo echoue

Temperatures plus precises :
- Nouvelle fonction fmtTempPrecise(c) qui affiche 1 decimale
  (25.8° au lieu de 26°)
- Appliquee a : temperature courante, ressenti, point de rosee,
  temperatures hourly (24 prochaines heures)
- Les H/L daily restent en entier pour rester lisibles

10 jours affiches : Open-Meteo renvoie forecast_days=10 jours,
le code de rendu daily itere deja sur daily.time.length donc
les 10 jours s'affichent automatiquement.
