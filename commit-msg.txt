feat: flamme 🔥 risque incendie par heure (FWI Open-Meteo)

Open-Meteo fournit un "fire_weather_index" (FWI, norme
canadienne) dans ses donnees horaires. Je l'affiche sous
forme d'une mini flamme dans chaque cellule horaire.

CLASSIFICATION (norme FWI canadienne)
- 0-5   : Faible   (caché)
- 5-15  : Modéré   (jaune, pulse leger)
- 15-30 : Élevé    (orange, pulse leger)
- >30   : Extrême  (rouge, pulse fort)

L'icone apparait a droite de l'icone meteo dans la
barre des 24 heures, avec infobulle au survol
("Risque incendie (FWI 23)").

SECURITES
- Cache si FWI < 5 (pas de risque reel)
- Cache si mm/h >= 3 (pluie abondante neutralise)
- Cache si POP >= 60 (pluie prevue suffit)
- Animation pulsee renforce le caractere urgent

IMPLEMENTATION
- hourly=...fire_weather_index (param Open-Meteo)
- Aucun appel API supplementaire
- Calcul local du seuil + classe CSS
- AUCUN flash entre init render et interpolation
  (applyHourlyInterpolation ne touche que le POP)

CSS
- .hour-fire (pastille blanche semi-transparente
  pour lisibilite sur tout fond)
- 3 classes : .moderate / .high / .extreme
- 2 animations : fire-pulse (2s) / fire-pulse-strong (1.4s)

Aucune autre fonctionnalite modifiee.
