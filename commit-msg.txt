fix: description unique, plus de double-affichage template+IA

Le user a signale qu'il voyait TOUJOURS 2 descriptions
se succeder : template puis IA.

Cause : meme avec shouldRefreshAIDescription qui
empeche de re-geneerer l'IA quand conditions stables,
renderCity etait appele toutes les 60s et reaffichait
le template au lieu de garder la description IA deja
presente.

Timeline du bug :
1. Premier render : template s'affiche (instant)
2. IA appelle en arriere-plan (1-5s)
3. IA remplace template avec son propre texte (fade)
4. 60s plus tard : renderCity re-appele
5. Template reaffiché a nouveau (bug !)
6. IA rappelle et reaffirme son texte (encore)

Le user voit donc 2 textes a chaque minute.

Fix : flag dataset.rendered sur descText
- Premier render (ou switchCity) : template s'affiche,
  flag pose a "1"
- Refresh suivants : on NE TOUCHE PLUS au DOM,
  la description reste fixe
- IA appelee mais ne fait rien si conditions stables
  (shouldRefreshAIDescription)
- Switch vers une autre ville : flag supprime pour
  que le template s'affiche a nouveau pour la nouvelle
  ville

Resultat : UNE description visible au lancement,
puis plus RIEN ne bouge tant que les conditions
meteo ne changent pas vraiment.
