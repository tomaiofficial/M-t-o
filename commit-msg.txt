fix: description IA fixee, ne change plus en boucle

Le user a signale que la description IA changeait toutes
les minutes : il voyait une description au lancement,
puis une autre 60s apres, puis une autre, etc. Tres
desagreable.

Cause : la precedente version regenerait la description
a chaque refresh (60s) et chaque appel LLM reformulait
meme pour des conditions stables, donc le texte changeait
constamment.

Fix : anti-flicker intelligent
- AI_CACHE_TTL_MS : 60 sec → 1 heure
- Slot aiCacheKey : 60 sec → 1 heure
- Nouvelle variable lastAIDescriptionWeather pour detecter
  un changement meteo
- Nouvelle fonction shouldRefreshAIDescription(prev, cur)
  qui decide si on doit regenere. Retourne false si les
  conditions sont stables :
  * meme weather_code
  * meme is_day (jour/nuit)
  * meme statut precip
  * temperature stable (< 3C d'ecart)
- refreshAIDescriptionAsync skip l'appel LLM si les
  conditions sont stables → la description est figee

Resultat : le user voit UNE description au lancement,
puis plus rien ne change tant que la meteo ne change
pas vraiment (ex: passage soleil -> pluie).

Libelle UI mis a jour : "Fixe, change si meteo evolue"

Hard refresh requis : Ctrl+Shift+R
