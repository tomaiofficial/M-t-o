BUG CRITIQUE : les 10 jours etaient invisibles

Cause : dans le commit precedent, j'ai ecrit
  if (hasData = true) di.classList.add("clickable");
au lieu de simplement di.className = "day clickable".

Resultat : `hasData = true` est une ASSIGNATION (pas une
comparaison). Comme hasData n'etait pas declare, ca creait
un global hasData=true puis le const hasData suivant
causait une SyntaxError qui empechait toute la boucle
de jours de s'executer.

Fix :
- di.className = "day clickable" (propre, sans bug)
